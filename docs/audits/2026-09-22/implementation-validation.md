# 全面改进与验证记录

日期：2026-09-22。对应分析：[项目审计](./project-review.md)。本次直接修改现有应用，保留工作区原有改动；验证使用临时目录和模拟服务，未触碰正式资料库。

## 使用流程

- 工作台提供搜索/提问入口、最近未读和需要处理的关注来源；去掉缺乏真实依据的检索能力展示。
- 添加资料分为“一次保存”和“持续关注”，高级选项折叠，预览可读，提交防重复且失败保留内容。
- 资料阅读采用窄列表与宽正文，原文/整理版切换，低频管理操作折叠；未读由用户确认，原文变化立即可见，不依赖 AI。
- 后台更新局部刷新，保留表单草稿；资料切换响应有版本检查，避免旧请求覆盖新选择。
- 对话存入服务端配置目录，兼容旧浏览器数据迁移，清空后不复活旧历史；连续写入按顺序保存。问答支持历史上下文和停止请求。
- 关注来源支持自定义实例域名与平台类型；浏览器脚本通过配对配置连接本地服务。

## 抓取与更新

- Jira/GitHub API 列表使用结构化条目，避免将 JSON 当 HTML 导致漏抓；批量子项完成后集中重建索引。
- Teams 部分抓取按稳定消息 ID 合并，保留旧消息和新增消息，支持编辑消息替换；可见行编号不作为平台 ID。
- 部分抓取、分页截断、身份依据、覆盖范围随资料保存；Confluence 评论失败保留旧评论，Jira 评论截断及 GitHub PR 缺 review 明确标记部分抓取。
- Teams 配置 Graph bearer 时走 API；浏览器会话操作串行化，临时会话在排队操作完成后关闭。
- HTTP 读取和模型响应设置体积上限，超时覆盖整个响应体；停止请求传播到抓取/模型流。
- 修复跨午夜调度；一次保存不偷偷订阅；相同 URL 更新串行化，同标题并发创建分配不同 ID。
- 整理结果有来源版本检查，防止长时间 AI 请求完成后覆盖更新的原文；原文未再次变化不会错误清除过期标记。

## 检索与模型边界

- 关键词与向量结果共用来源、标签、日期及隔离过滤。
- 每一次模型请求检查所用资料；禁止远程 AI 的来源和隔离资料不会进入对应模型请求或嵌入构建。
- 嵌入索引按内容哈希复用未变化资料，长文分块不再只覆盖开头。
- 模型流按 UTF-8 增量解码；聊天历史只接受有界的用户/助手消息。

## 存储与本地服务

- 条目采用暂存目录、事务清单、目录替换与启动恢复；读写、删除和索引构建共享队列，减少半写入与并发覆盖。
- 备份导入先验证路径、内容和资料结构，再在暂存目录重建索引并整体替换；失败保留原资料库。
- 配置原子写入；条目 ID 和备份路径拒绝穿越、符号链接与危险平台路径。
- 本地 API 检查 Host、Origin 和 JSON 类型；跨站脚本抓取需要配对 token。
- Electron 优先固定端口，正确处理 macOS 再激活和应用退出，外链限制为 HTTP(S)。

## 验证与边界

自动化覆盖真实 HTTP 应用、模拟模型服务、流取消与超时、完整 UI DOM 交互、存储事务恢复及备份失败回滚。最终运行结果见下方验收更新。

浏览器验收包括纯文本保存、资料原文阅读、无模型本地检索、刷新后会话保留，以及 1200px/390px 布局检查。截图保存在本目录的 `after-*.png`。

尚未验证真实企业账号/VPN下的 Jira、Confluence、Teams 全链路，也没有执行 Electron 安装包分发测试。Confluence 评论完整分页、GitHub PR review 实际采集、跨进程文件锁、持久化后台任务恢复仍是后续能力；当前通过部分抓取状态如实表达数据覆盖范围。嵌入增量构建仍可能阻塞首次检索，不等同于独立后台索引服务。

- `npm run check`：通过，覆盖新增策略、存储、备份、会话模块。
- `npm test`：72 项通过，0 失败、0 跳过。
- `git diff --check`：通过。
- 补充真实 HTTP 回归发现并修复普通网页抓取的不可达响应处理分支；测试同时覆盖预览、抓取保存与无 AI 更新计数。

- 引用跳转已实现；新回答去掉本地文件路径、内部 ID 等非必要技术信息。旧会话保留原始历史文字。
